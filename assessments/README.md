# Assessments & Mastery Gates

Use assessments to verify understanding before moving forward. Record attempts and evidence in `PROGRESS.md`.

## Assessment types
- **Knowledge check:** explain concepts without notes.
- **Implementation lab:** build a small working solution from requirements.
- **Debugging lab:** diagnose a deliberately broken example and document root cause.
- **Code review:** identify correctness, security, performance, and maintainability issues.
- **Design review:** explain architecture, alternatives, failure modes, and cost.
- **Capstone gate:** demonstrate a complete project with tests and documentation.

## Scoring rubric (0–4)
- 0 — Not attempted
- 1 — Can recognize the concept with guidance
- 2 — Can implement with references
- 3 — Can implement independently and test edge cases
- 4 — Can explain trade-offs, debug failures, and apply it in production-like scenarios

**Advance when:** core outcomes score at least 3, and any security/correctness-critical gaps have been resolved.
