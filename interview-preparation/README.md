# Interview Preparation

Prepare to explain, implement, test, and debug—not only recall definitions.

## Tracks
- Python language and runtime
- Data structures and algorithms
- SQL, data modeling, and data processing
- Probability, statistics, linear algebra, and optimization
- Classical machine learning and model evaluation
- Deep learning and PyTorch
- LLMs, embeddings, RAG, evaluation, and agents
- API design, distributed systems, security, and system design
- MLOps/LLMOps, observability, reliability, and cost
- Project deep-dives and behavioral interviews

## Answer framework
1. Clarify assumptions and constraints.
2. Explain a simple baseline.
3. Discuss correctness and edge cases.
4. Analyze complexity, quality, latency, and cost where relevant.
5. Cover failure modes, security, monitoring, and trade-offs.
6. State what you would test and how you would know it works.

Add topic-specific notes and practice problems in this directory as you progress.
