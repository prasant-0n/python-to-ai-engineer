# Project 08 — AI Agent Platform

**Focus:** controlled tool use, state, orchestration, and human oversight.

## Requirements
- Define explicit agent states, step limits, and execution timeouts.
- Validate every tool input and authorize every operation.
- Persist run history and trace each model/tool call.
- Handle retries, cancellation, partial results, and budget limits.
- Add adversarial tests for prompt injection and tool misuse.

## Completion evidence
Agent runs are bounded, auditable, testable, and safe to interrupt.
