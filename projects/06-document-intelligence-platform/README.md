# Project 06 — Document Intelligence Platform

**Focus:** reliable document processing with asynchronous jobs.

## Requirements
- Accept supported document types with size/type validation.
- Separate upload, parsing, extraction, and persistence concerns.
- Use a job queue with retries, timeouts, and idempotent processing.
- Track job states and provide clear failure details.
- Add tests for corrupt files, duplicate jobs, and partial failures.

## Completion evidence
Document processing is observable, recoverable, and safe to retry.
