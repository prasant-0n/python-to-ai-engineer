# Project 03 — Classical ML Service

**Focus:** end-to-end supervised ML and production inference.

## Requirements
- Establish a baseline and define an appropriate split strategy.
- Build preprocessing and training pipelines without data leakage.
- Compare metrics against a baseline and document limitations.
- Serialize the model and expose inference through FastAPI.
- Validate requests and test normal, invalid, and boundary inputs.

## Completion evidence
Training and inference are reproducible, metrics are justified, and the API has tests and health checks.
