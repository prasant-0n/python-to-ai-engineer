# Project 02 — Data Analysis Pipeline

**Focus:** data ingestion, validation, transformation, analysis, and reproducibility.

## Requirements
- Define a dataset contract and handle missing/invalid values.
- Build repeatable transformations with NumPy/Pandas.
- Include exploratory analysis and a concise report.
- Test data-quality rules and edge cases.
- Record assumptions and avoid leaking sensitive data.

## Completion evidence
A new user can reproduce the pipeline and understand the conclusions and limitations.
