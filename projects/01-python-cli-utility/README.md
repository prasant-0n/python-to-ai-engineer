# Project 01 — Python CLI Utility

**Focus:** Python fundamentals, packaging, type hints, validation, logging, and automated tests.

## Requirements
- Provide a useful command-line workflow with clear help output.
- Validate input and report actionable errors.
- Separate business logic from CLI parsing.
- Add type hints, unit tests, and a reproducible setup.
- Document usage, design choices, and known limitations.

## Completion evidence
A fresh clone can install and run the CLI, tests pass, and invalid input is handled predictably.
