# Portfolio Projects

Build projects in increasing complexity. Every project should include a clear problem statement, requirements, architecture, data model, API contract, security notes, tests, deployment instructions, observability, limitations, and a short demo.

## Project ladder
1. **Python CLI Utility** — packaging, typing, tests, and error handling.
2. **Data Analysis Pipeline** — NumPy/Pandas, validation, reproducibility, and reporting.
3. **Classical ML Service** — training pipeline, evaluation, model serialization, and FastAPI inference.
4. **AI Resume Analyzer** — structured extraction, scoring rubric, validation, and explainable output.
5. **RAG Knowledge Assistant** — ingestion, chunking, retrieval evaluation, citations, and access controls.
6. **Document Intelligence Platform** — parsing, asynchronous jobs, retries, and audit trails.
7. **AI Coding Assistant** — repository context, tool boundaries, evaluation, and safe failure behavior.
8. **AI Agent Platform** — bounded tools, state, permissions, tracing, and human approval.
9. **Multi-tenant AI SaaS** — tenant isolation, quotas, billing-aware usage, monitoring, and deployment.

## Project quality gate
A project is not complete just because it runs locally. Include automated tests, reproducible setup, realistic failure handling, a security review, and evidence that its core behavior works.
