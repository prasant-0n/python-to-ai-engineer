# Project 05 — RAG Knowledge Assistant

**Focus:** retrieval-augmented generation with measurable retrieval and answer quality.

## Requirements
- Build document ingestion, parsing, chunking, and indexing.
- Compare retrieval settings using a small labelled evaluation set.
- Return source citations and say when evidence is insufficient.
- Enforce document-level access controls and tenant boundaries.
- Test prompt injection, stale documents, and retrieval failures.

## Completion evidence
A repeatable evaluation reports retrieval/answer quality, latency, and approximate cost.
