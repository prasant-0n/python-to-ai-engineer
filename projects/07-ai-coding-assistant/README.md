# Project 07 — AI Coding Assistant

**Focus:** repository-aware assistance with bounded context and tools.

## Requirements
- Index code with file and symbol metadata.
- Respect ignore rules and exclude secrets and generated artifacts.
- Cite file paths and relevant snippets in responses.
- Keep tools permission-limited; require approval for consequential actions.
- Evaluate groundedness, usefulness, latency, and cost.

## Completion evidence
The assistant gives verifiable answers, refuses unsupported claims, and cannot silently perform unsafe actions.
