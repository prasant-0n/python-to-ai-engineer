# Python to AI Engineer

A structured, project-based curriculum from Python fundamentals to professional AI engineering. The repository is designed as a long-term learning system: learn concepts, implement them, test them, document trade-offs, and prove mastery with projects.

## Curriculum

| Phase | Focus |
|---|---|
| 00 | Engineering Foundation |
| 01 | Python Fundamentals |
| 02 | Intermediate Python |
| 03 | Advanced Python |
| 04 | Professional Python Engineering |
| 05 | Data Structures & Algorithms |
| 06 | Mathematics for AI |
| 07 | Scientific Python & Data Engineering |
| 08 | Machine Learning Engineering |
| 09 | Deep Learning & PyTorch |
| 10 | Generative AI, LLMs & Agentic AI |
| 11 | MLOps, LLMOps & Production AI Systems |

Start with [Phase 00](phases/phase-00-engineering-foundation/README.md), then follow the [course roadmap](ROADMAP.md). Record progress and evidence in [PROGRESS.md](PROGRESS.md).

## Repository Map

- `phases/` — phase outcomes, topics, and chapter materials
- `projects/` — progressive portfolio projects from Python CLI to multi-tenant AI SaaS
- `assessments/` — knowledge checks, implementation labs, and mastery gates
- `interview-preparation/` — interview topics and answer frameworks
- `resources/` — curated learning resources
- `docs/` — engineering and project documentation guidance
- `templates/` — reusable chapter and project templates
- `tests/` — automated checks for repository scaffold integrity

## Learning Workflow

1. Read the chapter objectives and prerequisites.
2. Study the concepts and run the examples.
3. Implement exercises independently before checking references.
4. Test edge cases and investigate failures.
5. Complete the assessment or project acceptance criteria.
6. Record evidence, gaps, and revision dates in `PROGRESS.md`.

## Quality Standard

Do not count a topic as mastered merely because you watched a course or copied code. Aim to explain the mental model, implement without step-by-step instructions, test failure cases, debug independently, and discuss relevant security, performance, reliability, and cost trade-offs.

## Local Checks

Use Python 3.12 or the version specified in `.python-version`.

```bash
python -m unittest discover -s tests
```

The course is an estimate, not a guarantee of job readiness. Advance based on demonstrated competence and working project evidence.
