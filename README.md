# Python to AI Engineer

A structured, project-based curriculum from Python fundamentals to professional AI engineering.

## Curriculum

- Phase 00: Engineering Foundation
- Phase 01: Python Fundamentals
- Phase 02: Intermediate Python
- Phase 03: Advanced Python
- Phase 04: Professional Python Engineering
- Phase 05: Data Structures & Algorithms
- Phase 06: Mathematics for AI
- Phase 07: Scientific Python & Data Engineering
- Phase 08: Machine Learning Engineering
- Phase 09: Deep Learning & PyTorch
- Phase 10: Generative AI, LLMs & Agentic AI
- Phase 11: MLOps, LLMOps & Production AI Systems

Read [ROADMAP.md](ROADMAP.md) and track learning in [PROGRESS.md](PROGRESS.md).

## Learning Workflow

1. Study the concepts and runnable examples.
2. Complete exercises independently.
3. Test your code and investigate mistakes.
4. Complete the chapter assessment.
5. Record evidence in `PROGRESS.md`.

The goal is demonstrated ability to explain, implement, test, debug, and evaluate—not simply to finish reading.
