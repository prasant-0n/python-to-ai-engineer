# Learning Resources

Maintain a curated, version-aware resource list. Prefer official documentation, foundational papers, high-quality textbooks, and courses with substantial exercises.

## Resource standards
For each resource, record: title, author/provider, URL, topic, level, why it is useful, prerequisite knowledge, and last-checked date.

## Categories
- Python language and standard library
- Software engineering, testing, typing, packaging, and tooling
- Algorithms and data structures
- Linear algebra, calculus, probability, and statistics
- NumPy, Pandas, SQL, and data engineering
- Machine learning and model evaluation
- Deep learning and PyTorch
- Transformers, LLMs, embeddings, and RAG
- AI evaluation, safety, and security
- MLOps, LLMOps, cloud, deployment, and observability

Avoid collecting resources without completing the associated exercises or building something with the material.
