# Engineering Documentation

Keep design and operational decisions close to the implementation.

## Suggested documents
- `product-requirements.md` — user problem, scope, requirements, non-goals, and success metrics.
- `architecture.md` — system context, components, data flows, and deployment view.
- `data-model.md` — entities, relationships, constraints, and lifecycle.
- `api-contracts.md` — endpoints, schemas, errors, and versioning.
- `security.md` — threat model, trust boundaries, secrets, privacy, and mitigations.
- `testing-strategy.md` — unit, integration, end-to-end, evaluation, and regression tests.
- `deployment.md` — environment configuration, release, rollback, and recovery.
- `observability.md` — logs, metrics, traces, alerts, and service objectives.

For substantial decisions, record context, alternatives, decision, consequences, and date.
