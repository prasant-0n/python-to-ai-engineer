# Learning Workflow

This repository is a practical learning curriculum. Keep lessons small, runnable, and verifiable.

## Chapter Completion
- Read objectives first.
- Run examples in a clean environment.
- Complete exercises before viewing solutions.
- Add tests for non-trivial behavior and failure cases.
- Record confusing concepts and resolved mistakes.
- Complete the assessment before marking a chapter complete.
- Update `PROGRESS.md`.

## Code Quality
- Use clear names and small functions.
- Explain non-obvious decisions rather than every line.
- Handle expected errors explicitly.
- Never commit credentials, tokens, private datasets, or local environment files.
- Record required Python and dependency versions.
- Keep examples deterministic where practical.

## Commit Message Examples
- `docs: add chapter on Python execution`
- `feat: implement fundamentals exercises`
- `test: add collection operation tests`
- `fix: handle invalid CLI input`
