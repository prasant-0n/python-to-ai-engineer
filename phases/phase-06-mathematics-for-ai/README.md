# Phase 06 — Mathematics for AI

## Topics
- Linear algebra: vectors, matrices, norms, products, eigenvalues, and SVD
- Calculus: derivatives, partial derivatives, gradients, chain rule, and Jacobians
- Probability and statistics: distributions, Bayes' theorem, inference, evaluation
- Optimization: gradient descent, regularization, numerical stability

## Project
Implement linear regression, logistic regression, and gradient descent with NumPy, then verify results against a trusted library.
