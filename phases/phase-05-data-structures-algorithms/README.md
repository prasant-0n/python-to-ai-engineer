# Phase 05 — Data Structures & Algorithms

## Topics
Complexity analysis, arrays, strings, hashing, stacks, queues, linked lists, searching, sorting, recursion, backtracking, two pointers, sliding window, heaps, trees, graphs, BFS/DFS, greedy algorithms, and dynamic programming.

## Practice Standard
Target 100–150 selected problems. For each, explain the approach, correctness, complexity, edge cases, and alternatives where meaningful.
