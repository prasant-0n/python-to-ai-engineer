# Phase 00 — Engineering Foundation

## Goal
Understand the development environment and the path from source code to program execution.

## Chapters
- [ ] 00.01 — How Python Executes a Program
- [ ] 00.02 — Interpreters, Compilers, Bytecode, and CPython
- [ ] 00.03 — Python Installation and Version Management

## Deliverable
A documented, reproducible Python environment and a small program with a basic test.

## Completion Criteria
- Explain source code, bytecode, and runtime execution.
- Confirm the Python version and executable.
- Create and activate a virtual environment.
- Install and track development dependencies.
- Run tests and make a documented Git commit.
