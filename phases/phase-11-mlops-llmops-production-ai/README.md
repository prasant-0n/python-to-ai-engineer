# Phase 11 — MLOps, LLMOps & Production AI

**Goal:** Ship AI systems that are observable, secure, reliable, cost-aware, and maintainable.

## Modules
- Packaging and reproducible environments
- Model and prompt versioning
- Experiment tracking and evaluation datasets
- CI/CD for ML and LLM applications
- Model serving with FastAPI
- Docker, deployment, and infrastructure fundamentals
- Monitoring: latency, errors, quality, drift, token use, and cost
- LLM tracing, prompt evaluation, and regression tests
- Security: secrets, PII, prompt injection, data access, and supply-chain risks
- Rollbacks, fallbacks, retries, rate limits, and incident response
- Responsible AI, documentation, and operational readiness

## Practical outcome
Deploy a versioned AI service with automated tests, health checks, structured logs, metrics, an evaluation suite, and a documented rollback plan.

## Completion gate
Demonstrate a reproducible deployment, explain its failure modes and cost drivers, and show how you would detect and recover from a quality or availability regression.
